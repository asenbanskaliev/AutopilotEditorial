# VS-112 RetroSpec — Print PDF renderer

## Implemented contract

VS-112 renders one deterministic print artifact from an exact current approved VS-111 authority. The implemented boundary includes geometry, page boxes, pagination, binding direction, paper/output intent, metadata, fonts, images, findings, decisions and immutable artifact identity.

## Learned constraints

- The materialized artifact must participate in replay identity; request-only replay is insufficient.
- Page number uniqueness and deterministic ordering are durable invariants.
- Font embedding permission and glyph coverage must be validated before persistence.
- Image rights, color profile, effective DPI and accessibility alternatives are approval inputs, not renderer warnings.
- Current state reconstruction from append-only history avoids process-memory authority.

## Preserved guarantees

- Provider-neutral Application contracts.
- Read-only upstream authority.
- Fail-closed workspace/project/digest/revision checks.
- Optimistic concurrency, atomic rollback, exact replay and deterministic Outbox.
- No release, publication or distribution behavior is introduced.
