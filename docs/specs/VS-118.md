# VS-118 — Professional release

## Intent

Freeze a professional release from the exact approved VS-117 proof authority and produce one immutable, reproducible release manifest for downstream installation and operations.

## Behaviors

1. A release request identifies workspace, project, exact VS-117 proof identity/revision/evidence digest, package authority, release channel, semantic version, locale, actor and deterministic request fingerprint.
2. The workflow requires the current approved VS-117 authority and rejects stale, missing, cross-workspace, digest-mismatched, rejected or superseded proof input.
3. Release assembly verifies every required manuscript, cover, metadata, accessibility, preflight and proof artifact by digest before freezing.
4. The canonical release manifest contains stable artifact ordering, media type, byte length, digest, provenance, source authority and required/optional classification.
5. Freeze is fail-closed when required artifacts, evidence, approvals or authority bindings are absent or inconsistent.
6. Approval freezes one immutable release identity, semantic version, manifest digest, artifact inventory digest and evidence digest; changes require a superseding release.
7. Exact replay is idempotent; conflicting reuse and stale revisions fail without duplicate release state or Outbox effects.
8. Requests, verified artifacts, manifests, decisions, replay receipts, append-only history and Outbox messages commit atomically and reconstruct from SQLite after restart.
9. No workflow claim implies external marketplace publication; this slice certifies the internal professional release boundary only.

## Invariants

- No approved release references stale, mismatched or non-approved VS-117 authority.
- Frozen artifacts are immutable and verified by digest and length.
- Canonical manifest ordering and hashing are deterministic.
- Exact replay cannot duplicate durable state or Outbox effects.
- Failed assembly, freeze, decision or transaction cannot expose a partially approved release.
- Workspace isolation and optimistic revision control apply to every read and mutation.

## Gates

- Typed request, authority, artifact, manifest, decision and state contracts.
- Exact VS-117 authority enforcement.
- Deterministic artifact verification and canonical manifest construction.
- Fail-closed freeze, approval and supersession semantics.
- Replay, optimistic concurrency, rollback, restart recovery and workspace isolation.
- Append-only history and deterministic exactly-once Outbox.
- Dual TDD GREEN, Auditoría M, Meta-Audit, RetroSpec and complete same-head CI.
