# VS-115 — Technical preflight

## Intent

Validate the exact approved VS-114 accessibility authority through a deterministic technical preflight before release packaging or publication.

## Behaviors

1. A preflight run identifies workspace, project, exact VS-114 run/revision/evidence digest, production artifact digest, target profile, locale, actor and deterministic request fingerprint.
2. The preflight requires the current approved VS-114 authority and rejects stale, missing, cross-workspace, digest-mismatched or non-approved input.
3. Checks validate package integrity, required parts and metadata, fonts and embedded resources, page geometry, links, images, profile conformance and artifact readability.
4. Check identity, version, rule profile, input digest and output digest are explicit and reproducible.
5. Findings use stable identities, severity, location, rule, evidence digest and remediation status.
6. Blocking findings prevent approval; waivers require explicit bounded evidence, expiry and approval.
7. Exact replay is idempotent; conflicting reuse and stale revisions fail without duplicate runs or Outbox effects.
8. Requests, executions, findings, waivers, decisions, receipts, append-only history and Outbox messages are committed atomically and reconstructed from SQLite after restart.
9. Approval freezes one immutable technical-preflight evidence digest for the next dependency-ready slice; changes require a superseding run revision.

## Invariants

- No approved preflight references stale or mismatched VS-114 authority.
- Identical governed inputs and checker versions produce deterministic evidence.
- Upstream authority is read-only.
- Exact replay cannot duplicate durable work or Outbox effects.
- Failed checks, decisions or transactions cannot expose an approved partial result.

## Gates

- Typed request, authority, execution, finding, waiver, decision and state contracts.
- Exact VS-114 authority enforcement.
- Deterministic checker normalization and evidence digests.
- Fail-closed approval semantics.
- Replay, optimistic concurrency, rollback, restart recovery and workspace isolation.
- Append-only history and deterministic exactly-once Outbox.
- Dual TDD GREEN, Auditoría M, Meta-Audit, RetroSpec and complete same-head CI.
