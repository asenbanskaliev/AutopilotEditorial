# VS-116 — Metadata KDP package

## Intent

Bind the exact approved VS-115 technical-preflight authority to complete, deterministic KDP metadata and an immutable publication package suitable for downstream proofing.

## Behaviors

1. A package request identifies workspace, project, exact VS-115 run/revision/evidence digest, manuscript and cover artifact digests, target marketplace, language, format profile, actor and deterministic request fingerprint.
2. The workflow requires the current approved VS-115 authority and rejects stale, missing, cross-workspace, digest-mismatched or non-approved input.
3. Metadata covers title, subtitle, contributors, description, keywords, categories, language, territories, publication rights, pricing intent, identifiers and AI-content disclosure without silently inventing values.
4. Required metadata is validated against the selected KDP format and marketplace profile; unresolved blocking gaps prevent package approval.
5. The package manifest binds every file path, media type, byte length and SHA-256 digest and is serialized canonically.
6. ZIP output is deterministic: normalized paths, stable ordering, fixed timestamps and no duplicate or unsafe entries.
7. Exact replay is idempotent; conflicting reuse and stale revisions fail without duplicate packages or Outbox effects.
8. Requests, metadata revisions, validation findings, decisions, manifests, package receipts, append-only history and Outbox messages are committed atomically and reconstructed from SQLite after restart.
9. Approval freezes one immutable metadata/package evidence digest for VS-117; changes require a superseding revision.

## Invariants

- No approved package references stale or mismatched VS-115 authority.
- Approved metadata contains no unresolved blocking field or profile violation.
- Identical governed inputs and profile versions produce identical manifests and package digests.
- Artifact contents are read-only and verified by digest before packaging.
- Exact replay cannot duplicate authoritative state or Outbox effects.
- Failed validation, packaging or transaction cannot expose a partially approved package.

## Gates

- Typed request, authority, metadata, validation finding, manifest, decision and state contracts.
- Exact VS-115 authority enforcement.
- Deterministic metadata normalization, canonical manifest and ZIP construction.
- Fail-closed required-field, rights, identifier and disclosure validation.
- Replay, optimistic concurrency, rollback, restart recovery and workspace isolation.
- Append-only history and deterministic exactly-once Outbox.
- Dual TDD GREEN, Auditoría M, Meta-Audit, RetroSpec and complete same-head CI.
