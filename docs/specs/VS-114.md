# VS-114 — Accessibility pipeline

## Intent

Evaluate the exact approved VS-113 production authority through a deterministic accessibility pipeline that combines automated checks with governed manual-review evidence before downstream technical preflight.

## Behaviors

1. An accessibility run identifies workspace, project, exact upstream render/revision/artifact digest, target profiles, locale, actor and deterministic request fingerprint.
2. The pipeline requires current approved VS-113 authority and rejects stale, missing, cross-workspace, digest-mismatched or non-approved input.
3. Automated analyzers produce normalized findings for document structure, reading order, headings, language, links, tables, images, alternatives, contrast and navigation.
4. Analyzer identity, version, rule profile, input digest and output digest are explicit and reproducible.
5. Manual review tasks identify scope, reviewer, required evidence, disposition and completion state without weakening automated findings.
6. Findings use stable identities, severity, location, rule, evidence digest and remediation status.
7. Blocking automated or manual-review findings prevent approval; waivers require explicit bounded evidence and governance.
8. Exact replay is idempotent; conflicting reuse and stale revisions fail without duplicate runs or Outbox effects.
9. Requests, analyzer executions, findings, manual reviews, waivers, decisions, receipts, append-only history and Outbox messages are committed atomically and reconstructed from SQLite after restart.
10. Approval freezes one immutable accessibility evidence digest for VS-115; changes require a superseding run revision.

## Invariants

- No approved accessibility result references stale or mismatched VS-113 authority.
- Identical governed inputs and analyzer versions produce deterministic normalized evidence.
- Upstream authority is read-only.
- Manual review cannot silently erase or downgrade automated findings.
- Exact replay cannot duplicate durable work or Outbox effects.
- Failed analysis, review or transaction cannot expose an approved partial result.

## Gates

- Typed request, authority, analyzer execution, finding, manual-review, waiver, decision and state contracts.
- Exact VS-113 authority enforcement.
- Deterministic analyzer normalization and evidence digests.
- Automated plus manual accessibility coverage with fail-closed blocking semantics.
- Waiver, repair, rejection, approval and supersession governance.
- Replay, optimistic concurrency, rollback, restart recovery and workspace isolation.
- Append-only history and deterministic exactly-once Outbox.
- Dual TDD GREEN, Auditoría M, Meta-Audit, RetroSpec and complete same-head CI.
