# VS-121 Dual TDD RED evidence

## RED-I

At slice start the product has many governed specialist workflows but no single typed authority that:

- accepts one natural-language creation brief;
- owns one global journey state;
- applies guided, supervised or autonomous continuation rules;
- computes the next safe phase from exact authorities;
- creates exception-only decisions;
- bounds repair loops;
- resumes after restart without user commands;
- freezes final release-readiness evidence.

## RED-E

The cumulative journey cannot yet prove that a user can describe an idea, approve only policy-required decisions and receive a governed final package without invoking CLI or MCP commands.

No PASS claim is permitted until implementation, cumulative tests, GREEN_EVIDENCE, Auditoría M, Meta-Audit, RetroSpec and same-head CI are complete.
