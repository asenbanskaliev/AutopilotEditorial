# VS-124 — RetroSpec

Status: IMPLEMENTED — pending same-head CI.

VS-124 adds a deployment-grade image provider boundary with a deterministic zero-cost reference adapter. It persists real SVG bytes atomically, records exact provenance, rights and accessibility evidence, enforces cost and territory policy, limits repair and safely reuses verified output after restart.

Retained boundaries:
- editorial approval still governs publication;
- external provider credentials and moderation are adapters;
- legal clearance is represented by evidence and fail-closed policy, not fabricated;
- restart reuse requires the exact artifact digest;
- publication cannot infer rights from image existence alone.
