# VS-125 — Commercial image moderation and external rights-clearance authority

## Intent
Connect provider-independent commercial image output to mandatory safety moderation and external rights-clearance verification inside the existing no-command image pipeline.

## Invariants
- Generated bytes are moderated and rights-cleared against their exact SHA-256 digest.
- Moderation and clearance decisions include stable external identifiers, policy/registry identity, timestamp, currency and cost.
- Clearance must agree with provider license reference and rights holder and cover the required territory.
- Provider plus verification cost never exceeds the configured ceiling.
- Verification evidence is written atomically and confined to the workspace.
- Restart reuse is allowed only for the same asset, digest, provider and provider request with approved decisions.
- Missing, contradictory, unsafe, uncleared, stale-by-digest or over-budget evidence fails closed.
- The existing bounded repair ceiling remains the only automatic retry authority.

## Acceptance
The executable integration smoke proves approved moderation and clearance, exact persisted verification evidence, deterministic restart reuse without external calls, unsafe rejection, uncleared-rights rejection and total-cost rejection.
