# Protocolo de reanudación

Al iniciar una nueva sesión:

1. leer `docs/execution/EXECUTION_STATUS.md`;
2. revisar PR abiertos;
3. revisar issues READY/BLOCKED;
4. revisar checks;
5. leer decisiones pendientes;
6. consultar Completion Matrix;
7. continuar desde el último gate válido.

No se pregunta qué se estaba haciendo si GitHub contiene la respuesta.

Al finalizar una sesión:

- worktree identificable;
- PR actualizado;
- status actualizado;
- issue comentado;
- evidencia guardada;
- siguiente acción registrada.
