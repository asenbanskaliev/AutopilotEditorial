# VS-140 — Professional Cover and Interior Layout

Defines deterministic print geometry and interior editorial rules.

Acceptance requires trim/bleed validation, page-count-dependent gutter, mirrored margins, recto chapter starts, suppressed headers on chapter openers, front-matter page-number suppression, widow/orphan controls, ordered front/back matter, body typography constraints, paper-specific spine calculation and a 300 DPI full-wrap cover canvas.
